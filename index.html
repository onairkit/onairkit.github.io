아래 썸네일은 이미지가 아니라 실제로 돌아가고 있는 위젯입니다. 카드를 누르면 그 위젯의 설정 화면으로 이동합니다.

URL Builder

설정하고, 복사하고, 붙여넣기

값을 바꾸면 아래 미리보기와 주소가 바로 바뀝니다. 기본값 그대로인 항목은 주소에서 자동으로 빠져서 URL이 짧게 유지됩니다. 설정은 이 브라우저에 저장되니 나중에 다시 와도 그대로예요.

설정

라이브 미리보기

실제 방송 화면(1920 × 1080)을 축소해 보여줍니다. 체크무늬는 배경이 투명하다는 뜻이라, OBS에서는 게임 화면이 그대로 비칩니다. 미리보기 안을 직접 클릭·조작해 볼 수도 있어요.

완성된 OBS 브라우저 소스 주소
HTML 파일 다운로드

다운로드한 파일에 이 설정을 그대로 쓰려면? OBS에서 “로컬 파일” 체크를 해제하고, URL 칸에 file:/// 로 시작하는 내 PC 경로 + 물음표 뒤 설정값을 직접 넣어야 합니다. 아래 OBS에 넣는 법 → 로컬 파일 탭에 그대로 따라 할 수 있게 적어 뒀어요.

Setup

OBS에 넣는 법 · 3단계

인터넷 주소를 그대로 쓰는 방법과, 파일을 내 PC에 받아 쓰는 방법이 있습니다. 처음이라면 온라인 URL 쪽이 훨씬 쉽습니다.

1

주소 복사하기

위 URL 빌더에서 원하는 대로 설정한 다음 [URL 복사] 버튼을 누릅니다. https://…/widgets/telop.html?theme=news 같은 주소가 복사됩니다.

2

브라우저 소스 추가

OBS 소스 목록에서 [+] → 브라우저를 고르고 이름을 정합니다. “로컬 파일” 체크는 끈 상태로 두세요.

3

URL 칸에 붙여넣기

URL 칸에 붙여넣고 폭 1920 / 높이 1080을 입력한 뒤 확인. 화면에서 크기와 위치는 마음대로 조절하면 됩니다.

이 방식의 장점

파일을 받아 둘 필요가 없고, 위젯이 개선되면 OBS를 껐다 켜는 것만으로 최신 버전이 적용됩니다. 대신 방송 PC가 인터넷에 연결돼 있어야 합니다.

1

HTML 파일 받기

위 빌더의 [HTML 파일 다운로드]를 누르면 telop.html 같은 파일 하나가 저장됩니다. 이 파일 하나가 위젯 전부입니다.

2

브라우저 소스 추가

OBS에서 [+] → 브라우저 → “로컬 파일” 체크 → 찾아보기로 방금 받은 파일을 선택합니다.

3

1920 × 1080 맞추기

폭 1920 / 높이 1080을 입력하고 확인. 인터넷이 끊겨도 동작하고, 파일을 메모장으로 열어 맨 위 CONFIG 값을 직접 고쳐도 됩니다.

⚠ 중요 — 로컬 파일 + 설정값을 같이 쓰려면

OBS의 “로컬 파일” 체크를 켜 두면 물음표 뒤 설정값(?theme=news)이 전부 무시됩니다. 받은 파일에 빌더에서 만든 설정을 적용하려면 이렇게 하세요.

① “로컬 파일” 체크를 해제합니다. → ② URL 칸에 file:/// 로 시작하는 내 PC 경로를 직접 입력합니다.
file:///C:/onairkit/widgets/telop.html?theme=news&label=속보

경로는 파일 탐색기 주소창에서 복사한 뒤 역슬래시(\)를 슬래시(/)로 바꾸면 됩니다. 폴더 이름에 띄어쓰기가 있어 잘 안 되면 그 부분만 %20 으로 바꿔 보세요. 빌더에서 복사한 주소의 물음표 뒷부분만 떼어다 붙여도 똑같이 동작합니다.

FAQ

자주 묻는 질문

정말 전부 무료인가요? 나중에 유료로 바뀌나요?

네, 지금 올라와 있는 위젯은 전부 무료입니다. 결제 페이지도, 로그인도, 사용 기간 제한도 없습니다.

가능한 이유는 단순합니다. 이 위젯들은 서버를 전혀 쓰지 않습니다. 계산도 저장도 전부 스트리머의 브라우저 안에서 일어나니 운영비가 0원이고, 그래서 구독료를 받을 이유가 없습니다. 저희는 화면 구석의 작은 크레딧과, 그걸 보고 오시는 커스텀 제작 문의로 먹고삽니다. 이미 배포된 파일을 나중에 유료로 잠그는 일은 없습니다.

구석에 뜨는 “온에어킷” 크레딧, 꺼도 되나요?

네, 꺼도 됩니다. 설정에서 크레딧 항목을 0 으로 바꾸거나 주소 끝에 &credit=0 을 붙이면 사라집니다. 다른 문구를 넣으면 그 문구로 바뀌기도 합니다(예: credit=내채널이름).

강제하지 않는 이유는, 크레딧을 남겨 주시는 분들 덕분에 다른 스트리머분들이 이걸 찾아오시기 때문입니다. 부담 없이 켜 두실 수 있다면 정말 큰 도움이 됩니다.

후원 알림(도네이션 알림)도 만들어 주시나요?

후원 알림은 트윕(Twip) 이나 투네이션(Toonation) 을 쓰시는 걸 권합니다. 두 곳 다 무료 알림 위젯을 제공하고, OBS 브라우저 소스로 넣는 방식이라 온에어킷 위젯과 나란히 겹쳐 써도 아무 문제 없습니다.

온에어킷은 결제·정산을 일절 처리하지 않습니다. 후원금을 받아 스트리머에게 전달하려면 전자금융거래법상 등록된 사업자여야 하고, 그건 저희가 할 수 있는 영역이 아닙니다. 돈이 오가는 부분은 검증된 서비스에 맡기고, 저희는 화면을 예쁘게 만드는 일에 집중하겠습니다.

업데이트는 어떻게 받나요?

온라인 URL 방식으로 넣으셨다면 아무것도 안 하셔도 됩니다. OBS를 껐다 켜거나 브라우저 소스를 새로고침하면 최신 버전이 적용됩니다.

로컬 파일 방식이라면 이 페이지에서 파일을 다시 받아 덮어쓰면 됩니다. 파라미터 이름과 동작은 되도록 바꾸지 않을 계획이라, 예전에 만들어 둔 주소는 그대로 쓰실 수 있습니다.

우리 채널 색·폰트에 맞춘 전용 디자인도 되나요?

됩니다. 색·모서리·폰트·애니메이션까지 채널 컨셉에 맞춘 커스텀 주문 제작을 받고 있습니다. 여기 없는 새로운 위젯(예: 랭킹 보드, 룰렛 변형, 시즌 한정 오버레이) 제작도 가능합니다.

다만 서버가 필요한 기능(채팅 자동 연동, 후원 연동, 여러 PC 간 값 동기화)은 이 프로젝트의 “서버 없음” 원칙상 만들지 않습니다. 만들어 달라는 요청은 디스코드로 주세요. 겹치는 요청이 쌓이면 그게 다음에 만들 위젯이 됩니다.

버그를 발견했어요 / 위젯이 화면에 안 보여요

먼저 아래 3가지를 확인해 보세요. 대부분 여기서 해결됩니다.

① 브라우저 소스 크기가 1920 × 1080 인지 (작게 잡으면 위젯이 화면 밖으로 밀려납니다)
② 로컬 파일인데 설정이 안 먹는다면 “로컬 파일” 체크가 켜져 있는지 (위 OBS 안내 참고)
③ 값이 이상하게 저장돼 있다면 주소 끝에 &reset=1 을 붙여 한 번 새로고침

그래도 안 되면 사용한 주소 전체 + OBS 버전 + 어떤 화면이 보이는지를 적어 디스코드나 GitHub 이슈로 보내 주세요. 재현만 되면 대부분 빠르게 고칩니다.

치지직·SOOP 말고 트위치·유튜브에서도 쓸 수 있나요?

네. 이 위젯들은 특정 플랫폼에 붙는 게 아니라 OBS의 브라우저 소스에 올라가는 웹 페이지입니다. OBS(또는 브라우저 소스를 지원하는 프로그램 — Streamlabs Desktop, XSplit 등)를 쓰신다면 어느 플랫폼으로 송출하든 똑같이 동작합니다.

기본 디자인만 국내 방송 자막 감성에 맞춰져 있을 뿐입니다.

카운터 숫자나 대기열은 OBS를 껐다 켜도 남아 있나요?

남아 있습니다. 카운터 값·대기열 명단·룰렛 남은 항목·타이머 진행 상태는 브라우저 저장소에 자동으로 기록돼서, 새로고침하거나 OBS를 재시작해도 이어집니다.

처음 상태로 되돌리고 싶을 때는 주소 끝에 &reset=1 을 붙이거나, 빌더의 “저장값 초기화” 스위치를 켜면 됩니다. 저장은 그 PC의 그 브라우저 안에만 있으니, 방송 PC를 바꾸면 값은 따라오지 않습니다.
