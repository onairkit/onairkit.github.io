## 1. OBS 설치하기

**OBS Studio**는 방송 화면을 만들고 송출하는 무료 프로그램입니다. 치지직·SOOP·트위치 모두 이걸 씁니다.

| 단계 | 할 일 |
|---|---|
| 1 | 웹 브라우저에서 **obsproject.com** 접속 |
| 2 | 본인 운영체제 버튼 클릭 (**Windows** / macOS / Linux) |
| 3 | 내려받은 설치 파일을 실행 → `Next` 를 계속 눌러 설치 |
| 4 | 처음 실행하면 **자동 구성 마법사**가 뜹니다. "방송에 최적화" 선택 후 진행하거나, 잘 모르겠으면 그냥 **취소**해도 됩니다 (위젯 사용에는 영향 없음) |

> **버전 확인** — 온에어킷 위젯은 OBS 28 이상을 권장합니다.
> OBS 메뉴 `도움말 → 정보` 에서 버전을 볼 수 있습니다. 27 이하라면 최신 버전으로 다시 설치하세요.
> (구버전은 내장 브라우저가 낡아서 위젯 애니메이션이 어색하게 나올 수 있습니다.)

### 화면 구성 익히기

OBS를 켜면 아래쪽에 상자 3개가 보입니다.

| 상자 이름 | 뜻 |
|---|---|
| **장면 (Scene)** | 방송 화면 한 세트. "게임 화면", "시작 대기 화면" 처럼 상황별로 만듭니다 |
| **소스 (Source)** | 장면 안에 올리는 재료 하나하나. 게임 캡처, 웹캠, 그리고 **위젯**이 전부 소스입니다 |
| **오디오 믹서** | 소리 조절. 위젯과는 상관없습니다 |

위젯은 **소스** 상자에서 추가합니다.

## 2. 온에어킷 파일 준비하기

1. 온에어킷 저장소 페이지에서 오른쪽 위 초록색 **`Code`** 버튼 → **`Download ZIP`** 클릭
2. 내려받은 ZIP 파일을 우클릭 → **압축 풀기**
3. 압축을 푼 폴더를 **경로가 짧고 한글·띄어쓰기가 없는 곳**으로 옮깁니다.

> **강력 권장 경로: `C:\onairkit`**
>
> 바탕화면(`C:\Users\사용자이름\Desktop\...`)에 두어도 대부분 잘 되지만,
> 사용자 이름이 한글이거나 폴더 이름에 띄어쓰기가 있으면 나중에 **파라미터 URL 방식**에서 문제가 생길 수 있습니다.
> 처음부터 `C:\onairkit` 에 두면 그 고민이 사라집니다.

4. 폴더 안 `widgets` 에 들어가서 아무 HTML 파일이나 **더블클릭**해 보세요.
   웹 브라우저가 열리면서 위젯이 보이면 준비 완료입니다.

## 3. 브라우저 소스 추가하기 — 로컬 파일 방식

**로컬 파일(local file)** = 내 컴퓨터 안에 있는 파일. 인터넷 없이 동작합니다.

| 단계 | 할 일 | 화면에서 볼 것 |
|---|---|---|
| 1 | 위젯을 올릴 **장면**을 먼저 선택 | 왼쪽 아래 "장면" 상자 |
| 2 | "소스" 상자 아래의 **`+`** 버튼 클릭 | 소스 종류 목록이 뜸 |
| 3 | **`브라우저`** 선택 | (영문판이면 `Browser`) |
| 4 | 이름 입력 (예: `텔롭`) → **확인** | 이름은 나중에 알아보기 쉬우면 아무거나 |
| 5 | **`로컬 파일` 체크박스를 켭니다** | 체크하면 URL 칸이 사라지고 "찾아보기" 버튼이 나타남 |
| 6 | **`찾아보기`** → `widgets` 폴더 → 원하는 HTML 파일 선택 | 예: `telop.html` |
| 7 | **폭에 `1920`, 높이에 `1080`** 입력 | ★ 이 값이 핵심입니다 |
| 8 | **확인** | 미리보기 화면에 위젯이 나타남 |

### 왜 꼭 1920 × 1080 인가요?

온에어킷 위젯은 **1920×1080 화면 전체를 캔버스로 쓰고, 그 안에서 `pos` 파라미터로 자기 위치를 잡습니다.**

- 폭·높이를 `800×200` 같은 작은 값으로 넣으면 → 위젯이 좁은 상자 안에 갇혀 잘리거나 겹칩니다.
- `1920×1080` 으로 넣으면 → 방송 화면과 정확히 같은 크기의 투명한 유리판이 하나 올라가고,
  그 유리판 위 지정된 자리에 위젯이 그려집니다. 배경은 투명하므로 게임 화면이 그대로 비칩니다.

방송 캔버스가 1280×720 이어도 상관없습니다. 브라우저 소스는 1920×1080 으로 만든 뒤,
OBS 미리보기에서 크기를 줄이면 깔끔하게 축소됩니다.

### 체크해 두면 좋은 옵션

브라우저 소스 속성 창 아래쪽 체크박스들입니다.

| 옵션 | 권장 | 이유 |
|---|---|---|
| 표시되지 않을 때 소스 종료 | **끄기** | 켜면 장면을 옮길 때마다 타이머·카운터가 새로 시작합니다 |
| 장면이 활성화될 때 브라우저 새로 고침 | **끄기** | 켜면 장면 전환할 때마다 위젯이 처음부터 다시 시작합니다 |
| 페이지 권한 제어 | 기본값 | 건드릴 필요 없습니다 |

> 단, 위젯을 **매번 처음부터 시작**하고 싶다면(예: 장면 전환할 때마다 룰렛 초기화)
> "장면이 활성화될 때 브라우저 새로 고침"을 켜는 게 편합니다. 취향껏 고르세요.

## 4. 브라우저 소스 추가하기 — 온라인 URL 방식

위젯 파일을 GitHub Pages 같은 곳에 올려 두고, **인터넷 주소로 불러오는** 방식입니다.
(직접 올리는 방법은 [배포가이드.md](배포가이드.md) 참고)

| 단계 | 할 일 |
|---|---|
| 1 | 소스 `+` → **브라우저** → 이름 입력 → 확인 |
| 2 | **`로컬 파일` 체크박스는 그대로 꺼 둡니다** (기본값이 꺼짐) |
| 3 | **URL** 칸에 위젯 주소를 붙여넣습니다 |
| 4 | 폭 `1920` / 높이 `1080` 입력 → 확인 |

주소 형태:

```
https://onairkit.github.io/widgets/telop.html
```

파라미터를 붙이면:

```
https://onairkit.github.io/widgets/telop.html?theme=news&label=속보&text=오늘 밤 9시 시청자 참여전
```

이 방식은 **주소 뒤에 `?파라미터=값` 을 그냥 붙이면 바로 먹힙니다.** 별도 설정이 필요 없습니다.

## 5. 두 방식 비교

| 항목 | 로컬 파일 방식 | 온라인 URL 방식 |
|---|---|---|
| 인터넷 필요 | 필요 없음 | **필요함** (끊기면 위젯이 안 뜸) |
| 준비 난이도 | 쉬움 (파일만 있으면 끝) | GitHub 계정 + 업로드 필요 |
| 파라미터 붙이기 | **번거로움** (아래 6번 함정 참고) | 쉬움 (주소 뒤에 그냥 붙임) |
| 위젯 업데이트 | ZIP을 다시 받아 덮어써야 함 | 저장소만 갱신하면 자동 반영 |
| 다른 PC에서 쓰기 | 파일을 옮겨야 함 | 주소만 알면 어디서든 |
| 파일 수정(내가 색·문구 직접 고치기) | **쉬움** (메모장으로 열어 수정) | 저장소에 올려야 반영 |
| 한글 경로 문제 | 생길 수 있음 | 없음 |
| 추천 대상 | 파일 하나 받아서 바로 쓰고 싶은 분 | 여러 대 PC, 자주 문구를 바꾸는 분 |

**결론적인 추천**

- **처음 써 보는 분** → 로컬 파일 방식으로 시작하세요. 5분이면 화면에 뜹니다.
- **파라미터를 자주 바꾸는 분** → 온라인 URL 방식이 압도적으로 편합니다.
- **인터넷이 불안정한 환경** → 무조건 로컬 파일 방식.

두 방식을 섞어 써도 됩니다. 같은 장면에 로컬 위젯과 온라인 위젯이 함께 있어도 아무 문제 없습니다.

## 6. ★ 로컬 파일 + 파라미터 함정 (가장 많이 막히는 곳)

**"로컬 파일" 체크를 켠 상태에서는 파라미터를 쓸 수 없습니다.**

이게 온에어킷을 쓰는 분들이 제일 많이 걸려 넘어지는 지점입니다.
"로컬 파일"을 체크하면 OBS는 URL 칸을 숨기고 파일 경로만 받습니다.
경로 뒤에 `?text=안녕` 을 억지로 붙이면 OBS는 그걸 **"?text=안녕 이라는 이름의 파일"** 로 이해하고 아무것도 못 찾습니다.

### 해결 방법

**"로컬 파일" 체크를 해제**하고, 다시 나타난 **URL 칸에 `file:///` 로 시작하는 주소**를 직접 넣습니다.

```
file:///C:/onairkit/widgets/telop.html?theme=news&label=속보&text=오늘 밤 9시 시청자 참여전
```

### 규칙 5가지

| 규칙 | 틀린 예 | 맞는 예 |
|---|---|---|
| 1. `file:///` 로 시작. 슬래시 **3개** | `file://C:/...` | `file:///C:/...` |
| 2. 경로 구분자는 **슬래시 `/`** (역슬래시 `\` 아님) | `file:///C:\onairkit\...` | `file:///C:/onairkit/...` |
| 3. 드라이브 문자에 콜론 유지 | `file:///C/onairkit/...` | `file:///C:/onairkit/...` |
| 4. 파일 이름 뒤에 `?` 하나, 그 뒤 파라미터를 `&` 로 연결 | `...telop.html?a=1?b=2` | `...telop.html?a=1&b=2` |
| 5. 파일 확장자 `.html` 을 빠뜨리지 말 것 | `...widgets/telop?text=..` | `...widgets/telop.html?text=..` |

### 경로를 확실하게 얻는 방법

1. 파일 탐색기에서 위젯 파일(`telop.html`)을 찾습니다.
2. 파일을 **Shift + 우클릭** → **"경로로 복사"** 클릭
3. 메모장에 붙여넣으면 `"C:\onairkit\widgets\telop.html"` 처럼 나옵니다.
4. **앞뒤 큰따옴표를 지우고**, **역슬래시 `\` 를 전부 슬래시 `/` 로 바꾸고**, 맨 앞에 `file:///` 를 붙입니다.
5. 그 뒤에 `?파라미터=값` 을 이어 붙입니다.

### 더 쉬운 확인 방법 (권장)

1. 그냥 위젯 HTML 파일을 **더블클릭**해서 브라우저(크롬/엣지)로 엽니다.
2. 브라우저 **주소창에 이미 `file:///C:/...` 형태의 정확한 주소**가 들어 있습니다.
3. 주소창 끝에 `?text=테스트&theme=news` 를 직접 타이핑하고 **Enter**.
4. 브라우저에서 원하는 대로 보이면, **그 주소창 내용을 통째로 복사**해서 OBS URL 칸에 붙여넣습니다.

브라우저에서 되면 OBS에서도 됩니다. 브라우저에서 안 되면 OBS에서도 안 됩니다.
**항상 브라우저에서 먼저 확인하세요.** 이게 가장 빠른 길입니다.

### 파라미터 값에 특수문자가 들어갈 때

| 넣고 싶은 것 | 어떻게 |
|---|---|
| 띄어쓰기 | 대부분 그냥 써도 됩니다. 안 되면 `%20` 으로 바꾸세요 (`오늘%20방송`) |
| 한글 | 그냥 쓰면 됩니다 |
| `&` (앤드 기호) | `%26` 으로 바꿔야 합니다. 안 그러면 거기서 파라미터가 끊깁니다 |
| `#` (샵) | `%23` 으로 바꾸세요. `accent=#00ffa3` 대신 `accent=00ffa3` 처럼 `#` 을 생략하는 게 편합니다 |
| `?` (물음표) | `%3F` |
| `\|` (세로줄) | 그냥 쓰면 됩니다. 단 `text`, `names`, `items` 에서는 **항목을 나누는 기호**로 쓰입니다 |

> `text` 나 `items` 안에 세로줄을 **글자 그대로** 넣을 수는 없습니다. 넣으면 그 자리에서 두 개로 잘립니다.

## 7. 크기와 위치 조절하기

브라우저 소스를 추가하면 OBS 미리보기 화면에 **빨간 테두리**가 생깁니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 위치 옮기기 | 소스 안쪽을 드래그 |
| 크기 조절 | 빨간 테두리의 **모서리 점**을 드래그 (모서리를 잡으면 비율이 유지됩니다) |
| 비율 무시하고 늘리기 | 변의 가운데 점을 드래그 — **권장하지 않습니다.** 글씨가 찌그러집니다 |
| 화면에 딱 맞추기 | 소스 우클릭 → `변환` → `화면에 맞추기` (단축키 `Ctrl + F`) |
| 위치·크기 초기화 | 소스 우클릭 → `변환` → `변환 초기화` (`Ctrl + R`) |
| 실수로 못 움직이게 잠그기 | 소스 목록에서 자물쇠 아이콘 클릭 |
| 숫자로 정확히 지정 | 소스 우클릭 → `변환` → `변환 편집` |

### 위치 조절, 두 가지 방법 중 무엇을 쓸까

| 방법 | 설명 | 언제 쓰나 |
|---|---|---|
| **OBS에서 드래그** | 브라우저 소스 자체를 옮기고 줄임 | 눈으로 보면서 미세 조정할 때. 대부분 이걸로 충분 |
| **`pos` + `margin` 파라미터** | 1920×1080 유리판 안에서 위젯이 붙을 모서리를 지정 | 여러 PC/장면에서 항상 같은 자리에 두고 싶을 때 |

**추천 조합** — 브라우저 소스는 1920×1080 · `변환 초기화` 상태로 두고,
`pos=br&margin=64` 처럼 파라미터로 자리를 잡습니다. 이러면 방송 캔버스가 바뀌어도 위치가 안 틀어집니다.

### 여러 위젯을 함께 쓸 때

위젯마다 **브라우저 소스를 따로** 만드세요. 하나의 소스에 두 위젯을 넣을 수는 없습니다.

- 각각 1920×1080 으로 만들고 `pos` 를 서로 다르게 주면 겹치지 않습니다.
  예: 텔롭 `pos=bl`, 카운터 `pos=tl`, 대기열 `pos=tr`
- **카운터를 2개 이상** 쓸 때는 반드시 `id` 파라미터를 다르게 주세요.
  안 그러면 두 카운터가 같은 저장 공간을 써서 숫자가 함께 움직입니다.
  ```
  file:///C:/onairkit/widgets/counter.html?label=데스&icon=💀&id=death&pos=tl
  file:///C:/onairkit/widgets/counter.html?label=승리&icon=🏆&id=win&pos=tr
  ```
- 소스 목록에서 **위에 있는 소스가 화면에서도 위에** 그려집니다. 가려지면 순서를 드래그해 바꾸세요.

## 8. 방송 중에 위젯 조작하기 (상호작용 창)

### 왜 마우스가 안 먹히나요?

OBS의 미리보기 화면은 **"보여 주는 화면"** 이지 **"조작하는 화면"** 이 아닙니다.
거기서 위젯 버튼을 클릭하면 위젯이 아니라 OBS의 소스 선택이 동작합니다.

위젯을 실제로 조작하려면 **상호작용(Interact) 창**을 열어야 합니다.

### 여는 법

1. **소스 목록**에서 해당 브라우저 소스를 **마우스 오른쪽 클릭**
2. 메뉴에서 **`상호작용`** (영문판 `Interact`) 선택
3. 작은 창이 하나 뜹니다. **이 창 안에서만** 마우스와 키보드가 위젯에 전달됩니다.

### 버튼이 안 보이는 게 정상입니다

온에어킷 위젯의 조작 버튼은 평소 **완전히 투명**(`opacity:0`, `pointer-events:none`)합니다.
**상호작용 창에서 위젯 위에 마우스를 올렸을 때(hover)만** 스르륵 나타납니다.

이건 버그가 아니라 의도된 설계입니다. 방송 송출 화면에는 조작 버튼이 절대 나가지 않습니다.

### 위젯별 조작

| 위젯 | 마우스 | 키보드 (상호작용 창을 한 번 클릭해 포커스를 준 뒤) |
|---|---|---|
| **텔롭** | 자막 바 위에 올리면 `이전` `일시정지` `다음` | `←` 이전 · `→` 다음 · `Space` 일시정지/재생 |
| **타이머** | `-1분` `+1분` `일시정지` `리셋` | `↑` +1분 · `↓` −1분 · `Space` 일시정지 · `R` 리셋 |
| **카운터** | `−` `+` `리셋` | `↑`/`+`/`=` 증가 · `↓`/`-`/`_` 감소 · `R` 리셋 (한글 자판이면 `ㄱ`) |
| **대기열** | 위쪽에 입력창 + `추가`, 각 줄에 올리면 `완료` `삭제` | 입력창 안 `Enter` 추가 · 입력창 밖 `Space`/`Enter` 맨 위 완료 · `R` 리셋 |
| **룰렛** | 원판 클릭 또는 가운데 `돌리기`, `리셋` | `Space` 돌리기 · `R` 리셋 (회전 중엔 입력 무시) |

> **버튼이 나타나는 위치**는 위젯이 화면 위쪽(`tl`/`tc`/`tr`)에 있으면 아래쪽에,
> 아래쪽(`bl`/`bc`/`br`)에 있으면 위쪽에 나타납니다. 화면 밖으로 잘리지 않게 하기 위해서입니다.
>
> **텔롭 예외** — `ticker`(흐르는 자막) 모드에서는 일시정지 버튼 하나만,
> `slide`/`fade` 모드인데 문구가 하나뿐이면 넘길 게 없으므로 버튼이 아예 나오지 않습니다.

### 상태 저장

카운터 숫자, 대기열 목록, 타이머 남은 시간, 룰렛 남은 항목, 텔롭 일시정지 상태는
브라우저 저장소(**localStorage**, 키 접두사 `onairkit:`)에 자동 저장됩니다.
**OBS를 껐다 켜도, 새로고침해도 그대로 유지됩니다.**

완전히 처음 상태로 되돌리려면 URL 뒤에 `&reset=1` 을 붙여 한 번 불러오거나, 상호작용 창에서 `R` 을 누르세요.

> `reset=1` 을 URL에 **계속 남겨 두면** 새로고침할 때마다 초기화됩니다.
> 한 번 초기화한 뒤에는 다시 지워 주세요.

## 9. 자주 겪는 문제 해결

### 9-1. 배경이 검게 나옵니다

**증상** — 게임 화면 위에 위젯을 올렸는데, 위젯 주변이 온통 검은 사각형으로 덮입니다.

**원인 후보**

| 원인 | 설명 |
|---|---|
| A. 소스 종류를 잘못 골랐다 | "브라우저"가 아니라 "이미지"나 "미디어 소스"로 추가했다 |
| B. 필터가 잘못 걸려 있다 | 이전에 넣은 크로마키/색상키 필터가 투명도를 망가뜨림 |
| C. OBS 하드웨어 가속 문제 | 그래픽 드라이버가 오래되어 투명 합성이 깨짐 |
| D. 파일을 잘못 열었다 | 위젯이 아니라 스크린샷 이미지를 올렸다 |

**해결 순서**

1. 소스를 우클릭 → `속성` → 창 제목에 **"브라우저"** 라고 적혀 있는지 확인. 아니면 지우고 브라우저로 다시 추가.
2. 소스를 우클릭 → `필터` → 목록에 뭔가 있으면 전부 선택해 `−` 로 제거.
3. 그 위젯 HTML 파일을 **크롬으로 직접 열어** 봅니다. 브라우저에서 흰 배경 위에 위젯이 뜨는 건 정상입니다
   (브라우저는 투명을 흰색으로 보여 줍니다). 이때 위젯이 정상이면 파일 문제는 아닙니다.
4. OBS `파일 → 설정 → 고급` 에서 특별히 바꾼 게 있으면 되돌립니다.
5. 그래픽 드라이버를 최신으로 업데이트한 뒤 OBS 재시작.
6. 그래도 안 되면 소스를 지우고 처음부터 다시 추가해 보세요. 이게 의외로 잘 듣습니다.

---

### 9-2. 위젯은 보이는데 글자가 안 뜹니다 / 아무것도 안 보입니다

**원인 후보**

| 원인 | 설명 |
|---|---|
| A. 폭·높이가 너무 작다 | `1920×1080` 이 아니면 위젯이 상자 밖으로 밀려나 안 보임 |
| B. `margin` 이 너무 크다 | `margin=400` 인데 소스가 작으면 위젯이 화면 밖으로 나감 |
| C. 소스 크기를 0에 가깝게 줄였다 | 드래그하다 실수로 납작하게 만든 경우 |
| D. 파라미터로 내용을 비웠다 | `label=` `title=` `icon=` 를 빈 값으로 주면 **그 부분을 일부러 숨기는 동작**입니다. (`text=` `names=` `items=` 처럼 내용 자체를 담는 파라미터는 비우면 숨김이 아니라 **기본 데모 값으로 되돌아갑니다**) |
| E. 소스 표시가 꺼져 있다 | 소스 목록의 눈 아이콘이 감겨 있음 |
| F. 위젯이 다른 소스에 가려졌다 | 게임 캡처가 위젯 위에 있음 |

**해결 순서**

1. 소스 목록에서 **눈 아이콘**이 켜져 있는지 확인.
2. 소스 우클릭 → `변환` → **`변환 초기화`** (`Ctrl+R`). 실수로 찌그러뜨린 크기가 원복됩니다.
3. 소스 우클릭 → `속성` → **폭 1920 / 높이 1080** 인지 확인.
4. 소스 목록에서 그 위젯을 **맨 위로** 드래그. 게임 캡처보다 위에 있어야 합니다.
5. 파라미터에서 `margin` 을 `48` 정도로 되돌립니다.
6. URL에서 파라미터를 **전부 지우고** 기본 상태로 한 번 불러와 보세요.
   기본 상태에서는 데모 문구가 반드시 보입니다. 보이면 파라미터 중 하나가 범인입니다.
   하나씩 다시 붙여 가며 어느 것이 문제인지 찾으세요.

> **텔롭에서 자막 바는 보이는데 왼쪽 칩만 없다** → 정상입니다. `label=` 로 비우면 칩이 숨겨집니다.
> `label=공지` 처럼 값을 채우면 다시 나옵니다.

---

### 9-3. 폰트(글꼴)가 깨집니다 / 네모(□□□)로 나옵니다 / 못생긴 글씨로 나옵니다

**원인**

온에어킷은 **Pretendard**라는 무료 한글 글꼴을 인터넷(jsDelivr CDN)에서 불러옵니다.
이걸 못 불러오면 시스템 기본 글꼴(맑은 고딕 등)로 대체됩니다. 동작은 하지만 모양이 달라 보입니다.

| 원인 | 설명 |
|---|---|
| A. 인터넷 연결 없음 | 글꼴 CDN에 접근 실패 |
| B. 방화벽/백신이 CDN 차단 | 회사·학교 네트워크에서 흔함 |
| C. 글꼴 로딩 전에 스크린샷을 봤다 | 소스를 막 추가한 직후 0.5초 정도 기본 글꼴로 보임 |
| D. 한글이 네모(□)로 나온다 | 이건 글꼴이 아니라 **인코딩 문제**일 가능성이 큼 (아래 9-5 참고) |

**해결 순서**

1. 소스 우클릭 → **`새로고침`**. 대부분 이걸로 끝납니다.
2. 크롬에서 `https://cdn.jsdelivr.net` 이 열리는지 확인. 안 열리면 네트워크가 막힌 것입니다.
3. 방화벽·백신에서 OBS를 예외로 추가.
4. **글꼴이 안 떠도 위젯 기능에는 문제가 없습니다.** 인터넷이 계속 안 되는 환경이면 그냥 쓰셔도 됩니다.
5. 굳이 맞추고 싶다면 [Pretendard 공식 배포처](https://github.com/orioncactus/pretendard)에서 글꼴을 내려받아
   **Windows에 설치**하세요. 시스템에 설치되어 있으면 CDN 없이도 같은 모양이 나옵니다.

### 9-4. 파라미터가 안 먹힙니다

가장 흔한 문제입니다. 아래를 **위에서부터 순서대로** 확인하세요.

| # | 확인할 것 | 어떻게 |
|---|---|---|
| 1 | **"로컬 파일" 체크가 켜져 있지 않은가** | 켜져 있으면 파라미터는 100% 무시됩니다. 체크 해제 후 URL 칸에 `file:///...` 로 다시 입력 → [6번 항목](#6--로컬-파일--파라미터-함정-가장-많이-막히는-곳) |
| 2 | **물음표가 하나뿐인가** | 첫 파라미터 앞에만 `?`, 나머지는 전부 `&`. `?a=1?b=2` (X) → `?a=1&b=2` (O) |
| 3 | **파라미터 이름의 철자·대소문자** | 전부 **소문자**입니다. `Text` `SIZE` (X) → `text` `size` (O) |
| 4 | **값이 허용 범위 안인가** | 범위를 벗어나면 조용히 잘려 나갑니다. `size=999` → `120` 으로 처리 |
| 5 | **그 위젯에 있는 파라미터인가** | `minutes` 는 타이머 전용, `items` 는 룰렛 전용입니다. 위젯 파일 상단 주석의 파라미터 표를 확인 |
| 6 | **모드 전용 파라미터가 아닌가** | 텔롭 `interval` 은 `slide`/`fade` 에서만, `speed` 는 `ticker` 에서만 동작. 타이머 `until` 은 `mode=until` 에서만 |
| 7 | **저장된 값이 덮어쓰고 있지 않은가** | 카운터 `value`, 대기열 `names`, 룰렛 `items` 는 **저장된 값이 우선**입니다. `&reset=1` 을 붙여 한 번 불러오세요 |
| 8 | **크롬 주소창에서 되는가** | 크롬에서 그 URL을 그대로 열어 확인. 크롬에서 되는데 OBS에서 안 되면 URL 붙여넣기가 잘린 것입니다 |

> **7번은 정말 자주 걸립니다.** "값을 0으로 바꿨는데 화면은 계속 7이에요" → localStorage에 저장된 7이 이깁니다.
> URL 끝에 `&reset=1` 을 붙여 한 번 불러온 뒤, 다시 지우세요.

### 9-5. 한글 경로 문제

**증상** — `file:///C:/Users/사용자/Desktop/취미/onairkit/...` 처럼 경로에 한글이 있을 때
위젯이 아예 안 뜨거나, OBS에 "파일을 찾을 수 없음"이 나옵니다.

**원인** — 브라우저·OBS가 한글을 URL 인코딩(문자를 `%EC%B7%A8` 같은 코드로 바꾸는 것)하는 방식이 서로 달라
같은 경로를 다른 파일로 인식하는 경우가 있습니다. 띄어쓰기가 섞이면 더 잘 깨집니다.

**해결 순서 (위에서부터 시도)**

1. **가장 확실한 방법 — 폴더를 옮기세요.**
   `C:\onairkit` 처럼 **한글·띄어쓰기·특수문자가 전혀 없는 짧은 경로**로 통째로 옮깁니다.
   대부분 이 한 번으로 끝납니다. 시간 아끼려면 이것부터 하세요.
2. 옮길 수 없다면 **크롬 주소창에서 얻은 인코딩된 주소**를 씁니다.
   - 위젯 HTML을 더블클릭해 크롬으로 엽니다.
   - 주소창을 클릭하면 원래 한글로 보이지만, **주소창 내용을 복사해 메모장에 붙여넣으면**
     `%EC%B7%A8%EB%AF%B8` 같은 인코딩된 형태로 나옵니다.
   - 그 인코딩된 주소를 OBS URL 칸에 붙여넣습니다.
3. 띄어쓰기가 있다면 `%20` 으로 직접 바꿉니다. (`내 폴더` → `%EB%82%B4%20...`)
4. 그래도 안 되면 **"로컬 파일" 체크 방식**을 쓰세요. 이 방식은 OBS가 경로를 직접 다루므로
   한글 경로에서도 잘 동작합니다. 대신 파라미터는 못 쓰니, 위젯 파일을 메모장으로 열어
   `CONFIG` 값을 직접 고치는 방식으로 설정하세요.

> **메모장으로 고칠 때 주의** — 저장할 때 인코딩이 **UTF-8** 인지 확인하세요.
> 메모장 `다른 이름으로 저장` 창 아래쪽에 인코딩 선택란이 있습니다.
> `ANSI` 로 저장하면 한글이 전부 깨집니다(□□□ 또는 알 수 없는 기호).
> 가능하면 메모장 대신 **VS Code** 나 **Notepad++** 를 쓰는 것이 안전합니다.

### 9-6. 위젯이 갱신되지 않습니다 (캐시 문제)

**증상** — 파일을 고치거나 파라미터를 바꿨는데 OBS 화면은 예전 그대로입니다.

**원인** — OBS 내장 브라우저가 예전 내용을 **캐시(cache, 임시 저장)** 해 두고 계속 보여 주는 것입니다.

**해결 순서 (가벼운 것부터)**

1. 소스 목록에서 그 소스를 **우클릭 → `새로고침`**. (영문판 `Refresh` / 속성 창 안의 `현재 페이지 새로 고침` 버튼도 동일)
2. 소스 우클릭 → `속성` → 아무것도 바꾸지 않고 **`확인`**. 이것만으로도 다시 불러오는 경우가 많습니다.
3. URL 끝에 **의미 없는 값을 하나 붙여** 다른 주소인 척합니다.
   ```
   ...telop.html?text=안녕&v=2
   ```
   다음에 또 안 바뀌면 `v=3`, `v=4` 로 올리세요. 온에어킷 위젯은 모르는 파라미터를 무시하므로 안전합니다.
4. **OBS를 완전히 껐다 켭니다.**
5. 그래도 안 되면 OBS 캐시 폴더를 비웁니다.
   - OBS를 완전히 종료
   - `Win + R` → `%APPDATA%\obs-studio\plugin_config\obs-browser` 입력 → Enter
   - 그 안의 `Cache`, `Code Cache`, `GPUCache` 폴더를 삭제
   - OBS 재시작
6. **온라인 URL 방식**을 쓴다면 GitHub Pages 쪽 캐시일 수도 있습니다. 배포 후 몇 분 기다린 뒤 다시 확인하세요.

> **저장된 값과 캐시는 다릅니다.** 카운터 숫자가 안 바뀌는 건 캐시가 아니라 localStorage 때문입니다.
> 그 경우는 `&reset=1` 을 쓰세요 ([9-4의 7번](#9-4-파라미터가-안-먹힙니다)).

### 9-7. 조작 버튼이 안 보입니다

**증상** — 위젯은 잘 뜨는데 `+` `−` `돌리기` 같은 버튼이 어디에도 없습니다.

**이건 대부분 정상입니다.** 온에어킷 위젯의 조작 버튼은 방송 화면에 나가지 않도록
평소 완전히 투명하게 숨겨져 있습니다.

**해결 순서**

1. 소스 목록에서 그 브라우저 소스를 **우클릭 → `상호작용`**.
2. 뜬 작은 창 **안에서**, 위젯 위에 **마우스를 올립니다(hover)**. 그러면 버튼이 나타납니다.
   - OBS 미리보기 화면에 마우스를 올리는 게 아닙니다. **반드시 상호작용 창 안**이어야 합니다.
3. 키보드를 쓰려면 상호작용 창을 **한 번 클릭해 포커스**를 준 뒤 누르세요.
4. 그래도 안 나오면 아래를 확인하세요.

| 상황 | 이유 |
|---|---|
| 텔롭인데 버튼이 하나도 없다 | `slide`/`fade` 모드에서 문구가 **하나뿐**이면 넘길 게 없어 버튼이 안 나옵니다. `text` 에 `\|` 로 문구를 2개 이상 넣어 보세요 |
| 텔롭인데 일시정지 버튼만 있다 | `mode=ticker` 에서는 정상입니다 |
| 상호작용 창이 메뉴에 없다 | 그 소스가 "브라우저"가 아닙니다. 소스 종류를 확인하세요 |
| 버튼이 화면 밖에 있는 것 같다 | `margin` 을 20 이상으로 키우고, 상호작용 창을 더 크게 늘려 보세요 |
| 타이머가 `onend=hide` 로 사라졌다 | 사라진 자리에 마우스를 올리면 흐릿하게 다시 나타나 `리셋` 을 누를 수 있습니다 |

### 9-8. 그 밖에

| 증상 | 해결 |
|---|---|
| 위젯이 방송에서만 안 보인다 | 그 소스가 **다른 장면**에 있는지 확인. 장면마다 소스는 따로입니다 (`기존 항목 추가`로 공유 가능) |
| 애니메이션이 뚝뚝 끊긴다 | OBS `설정 → 비디오` 의 FPS를 30 이상으로. 브라우저 소스는 OBS FPS를 따라갑니다 |
| CPU 사용률이 너무 높다 | 브라우저 소스 개수를 줄이거나, 안 쓰는 장면의 소스에 "표시되지 않을 때 소스 종료"를 켜세요 |
| 카운터 두 개가 같이 움직인다 | `id` 파라미터를 서로 다르게 주세요 (`id=death`, `id=win`) |
| 타이머가 OBS를 껐다 켜면 이상한 시간부터 시작한다 | 저장된 상태가 이어진 것입니다. `&reset=1` 로 한 번 초기화하세요 |
| 위젯이 화면 오른쪽 아래로 조금 삐져나간다 | `margin` 을 20 이상으로 주세요. 크레딧이 위젯 아래에 붙어 있어 여백이 0에 가까우면 잘립니다 |
| 글자가 너무 크거나 작다 | `size` 파라미터(16~120)로 조절하거나, OBS에서 소스 크기를 조절하세요 |

## 그래도 안 될 때

1. **위젯 HTML 파일을 메모장으로 열어 맨 위 주석을 읽어 보세요.** 그 위젯의 전체 파라미터 표와 실제로 동작하는 예시 URL이 한국어로 들어 있습니다.
2. **크롬에서 먼저 테스트하세요.** 크롬에서 되면 OBS 설정 문제, 크롬에서도 안 되면 URL/파라미터 문제입니다.
3. 그래도 해결이 안 되면 저장소 **Issues** 에 아래를 적어 올려 주세요.
   - 어떤 위젯인지 (파일 이름)
   - 사용한 **전체 URL** (경로에 개인정보가 있으면 가려도 됩니다)
   - 기대한 모습 / 실제 나온 모습
   - OBS 버전, Windows인지 macOS인지
