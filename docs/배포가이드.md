# 배포 가이드 — GitHub Pages에 온에어킷 올리기

이 문서를 따라 하면 **내 위젯을 인터넷 주소로 만들 수 있습니다.**

```
https://onairkit.github.io/widgets/telop.html?text=안녕하세요
```

이런 주소가 생기면 OBS에 파일을 넣을 필요 없이 **주소만 붙여넣으면** 됩니다.
다른 PC에서도, 노트북에서도, 친구에게 알려 줄 때도 주소 하나면 끝납니다.

| 항목 | 내용 |
|---|---|
| 비용 | **0원** (GitHub Pages는 공개 저장소에 무료) |
| 필요한 것 | GitHub 계정, 웹 브라우저 |
| 걸리는 시간 | 10~15분 (처음 한 번만) |
| 명령어 프로그램 | **필요 없습니다.** 웹 화면만으로 전부 가능합니다 |

> **GitHub란?** 파일을 온라인에 보관하고 버전을 관리해 주는 서비스입니다.
> **GitHub Pages란?** 그 저장소 안의 HTML 파일을 그대로 웹사이트처럼 보여 주는 무료 기능입니다.
> 우리에게 필요한 건 딱 이 두 가지뿐입니다.

## 0. 시작 전 확인

배포할 폴더 안이 이렇게 되어 있어야 합니다.

```
onairkit/
├── .nojekyll        ★ 반드시 있어야 합니다 (내용이 빈 파일)
├── index.html       ★ 랜딩 페이지 + URL 빌더 (저장소 주소를 열면 이게 보입니다)
├── README.md
├── LICENSE
├── CLAUDE.md
├── widgets/
│   ├── telop.html
│   ├── timer.html
│   ├── counter.html
│   ├── queue.html
│   └── roulette.html
└── docs/
    ├── OBS설정법.md
    └── 배포가이드.md
```

> `index.html` 이 루트에 있으므로, 배포 후 `https://onairkit.github.io/` 를 열면
> README가 아니라 **랜딩 페이지**가 뜹니다. 커뮤니티에는 이 주소를 공유하세요.

> **`.nojekyll` 이 왜 필요한가요?**
> GitHub Pages는 기본적으로 Jekyll이라는 처리기를 거치는데, 이때 밑줄(`_`)로 시작하는 폴더나 일부 파일을
> 무시해 버립니다. `.nojekyll` 이라는 빈 파일을 두면 **파일을 있는 그대로 올려 줍니다.**
> 지우지 마세요.

**공개 범위에 대해** — GitHub Pages 무료 사용은 **공개(Public) 저장소**여야 합니다.
즉 여기 올린 파일은 누구나 볼 수 있습니다. 개인정보, 방송 키, 비밀번호가 들어간 파일은 절대 넣지 마세요.
온에어킷 위젯 파일에는 그런 게 전혀 없으니 안심하셔도 됩니다.

## 1. onairkit 조직 만들기

**개인 계정(`dngus64bp-commits`)은 이미 있습니다.** 여기에 바로 올리지 않고 `onairkit` 이라는
**조직(Organization)** 을 하나 만들어서 그 아래에 올립니다. 조직 생성은 **무료**입니다.

> **왜 조직을 따로 만드나요?**
> 개인 계정에 올리면 주소가 `https://dngus64bp-commits.github.io/onairkit/` 가 됩니다.
> 조직으로 만들면 **`https://onairkit.github.io/`** 가 됩니다.
> 위젯 구석 크레딧("온에어킷")을 보고 검색해 찾아오는 게 이 프로젝트의 1단계 유입 경로인데,
> 주소가 브랜드와 일치해야 그 흐름이 끊기지 않습니다.
> 나중에 도메인을 사서 붙이거나, 사업이 커져 계정을 분리할 때도 이미 준비된 상태가 됩니다.

| 단계 | 할 일 |
|---|---|
| 1 | github.com 에 `dngus64bp-commits` 로 로그인 |
| 2 | 오른쪽 위 프로필 아이콘 → **`Your organizations`** |
| 3 | **`New organization`** 클릭 |
| 4 | 요금제에서 **`Free`** 선택 |
| 5 | **Organization name** 에 **`onairkit`** 입력 (소문자) |
| 6 | 연락 이메일 입력, "My personal account" 선택 |
| 7 | 멤버 초대 화면은 **건너뛰기(Skip)** |

> **`onairkit` 이름이 이미 쓰이고 있다면** 다른 이름을 골라야 합니다.
> 2026-08-18 기준으로는 비어 있는 것을 확인했지만, 선점당했을 수 있습니다.
> 이름이 바뀌면 이 문서와 저장소 안의 주소를 전부 함께 고쳐야 합니다.

## 2. 저장소(repository) 만들기

**저장소(repository, 줄여서 repo)** = 프로젝트 하나가 들어가는 폴더라고 생각하면 됩니다.

| 단계 | 할 일 | 입력값 |
|---|---|---|
| 1 | `onairkit` 조직 화면에서 **`New repository`** 클릭<br>(Owner 가 **`onairkit`** 인지 반드시 확인) | |
| 2 | **Repository name** 입력 | **`onairkit.github.io`** ← 점까지 정확히 |
| 3 | Description (설명, 선택) | 예: `무료 OBS 위젯 모음` |
| 4 | 공개 범위 선택 | **`Public`** ← 반드시 Public |
| 5 | `Add a README file` 체크박스 | **체크하지 마세요** (이미 README.md가 있습니다) |
| 6 | `.gitignore` / `license` 선택 | **둘 다 `None`** (이미 있습니다) |
| 7 | 아래 **`Create repository`** 클릭 | |

> **저장소 이름이 왜 `onairkit.github.io` 인가요?**
> GitHub에는 특별 규칙이 하나 있습니다. 저장소 이름을 **`<조직이름>.github.io`** 로 지으면
> 그 저장소가 **조직의 대표 사이트**가 되어 주소에서 저장소 이름 부분이 사라집니다.
>
> | 저장소 이름 | 위젯 주소 |
> |---|---|
> | **`onairkit.github.io`** ← 이걸로 만듭니다 | `https://onairkit.github.io/widgets/telop.html` |
> | `onairkit` | `https://onairkit.github.io/onairkit/widgets/telop.html` (경로가 한 번 더 붙습니다) |
>
> 이름을 다르게 지으면 이 문서의 모든 예시 주소가 틀어집니다. **점까지 정확히** 입력하세요.

만들고 나면 "Quick setup" 이라는 안내 화면이 나옵니다. 여기서 두 갈래로 나뉩니다.

- **명령어가 부담스럽다** → [방법 A. 웹에서 파일 끌어다 올리기](#방법-a-웹에서-파일-끌어다-올리기-초보자-추천)
- **명령어를 쓸 수 있다 / 앞으로 자주 수정할 예정이다** → [방법 B. git 명령으로 올리기](#방법-b-git-명령으로-올리기)

두 방법 중 **하나만** 하면 됩니다. 결과는 똑같습니다.

## 방법 A. 웹에서 파일 끌어다 올리기 (초보자 추천)

프로그램 설치도, 명령어도 필요 없습니다. 웹 화면에 파일을 끌어다 놓기만 하면 됩니다.

### A-1. 업로드 화면 열기

1. 방금 만든 저장소 화면에서 **`uploading an existing file`** 링크를 클릭합니다.
   (안 보이면 저장소 주소 뒤에 `/upload/main` 을 직접 붙여 들어가세요.
   예: `https://github.com/onairkit/onairkit.github.io/upload/main`)

### A-2. 파일과 폴더 끌어다 놓기

2. 파일 탐색기에서 `onairkit` 폴더를 엽니다.
3. 폴더 **안의 내용물**을 전부 선택합니다. (`Ctrl + A`)
   - `README.md`, `LICENSE`, `CLAUDE.md`, `.nojekyll`, `widgets` 폴더, `docs` 폴더
   - **`onairkit` 폴더 자체를 통째로 끌지 마세요.** 안의 내용물만 올려야 주소가 깔끔합니다.
4. 선택한 것들을 브라우저의 점선 상자 안으로 **드래그 앤 드롭**합니다.
5. 파일 목록이 화면에 뜰 때까지 기다립니다. 폴더도 그대로 유지됩니다.

> **`.nojekyll` 이 안 보인다면** — 점(`.`)으로 시작하는 파일은 Windows에서 기본으로 숨겨져 있습니다.
> 파일 탐색기 상단 `보기` → `표시` → **`숨긴 항목`** 을 체크하면 보입니다.
> 그래도 없으면 [A-4](#a-4-nojekyll-파일이-없을-때-웹에서-만들기)를 참고해 웹에서 직접 만드세요.

### A-3. 커밋(저장)하기

6. 화면 아래 **Commit changes** 칸에 설명을 적습니다. (예: `온에어킷 위젯 5종 첫 배포`)
7. **`Commit changes`** 초록 버튼 클릭.
8. 업로드 완료. 저장소 화면에 파일들이 보이면 성공입니다.

이제 [3단계: GitHub Pages 켜기](#3-github-pages-켜기)로 가세요.

### A-4. `.nojekyll` 파일이 없을 때 웹에서 만들기

1. 저장소 화면에서 **`Add file`** → **`Create new file`**
2. 파일 이름 칸에 **`.nojekyll`** 입력 (내용은 비워 둡니다)
3. 아래 **`Commit changes`** → 초록 버튼 클릭

## 방법 B. git 명령으로 올리기

파일 수정이 잦다면 이쪽이 훨씬 빠릅니다. 한 번 설정해 두면 다음부터는 3줄이면 배포가 끝납니다.

### B-1. Git 설치 확인

PowerShell(윈도우 검색창에 `powershell`)을 열고:

```powershell
git --version
```

`git version 2.xx.x` 처럼 나오면 설치되어 있습니다.
"인식할 수 없습니다" 라고 나오면 **git-scm.com** 에서 Git for Windows를 받아 설치하세요.
설치할 때는 전부 기본값(`Next`)으로 두면 됩니다. 설치 후 PowerShell을 **껐다 다시 여세요.**

### B-2. 이름·이메일 등록 (처음 한 번만)

커밋에 기록될 작성자 정보입니다. GitHub 가입 정보와 같게 넣으세요.

```powershell
git config --global user.name "dngus64bp-commits"
git config --global user.email "가입한@이메일.com"
```

### B-3. 폴더로 이동해서 올리기

`onairkit` 폴더 경로로 이동한 뒤, 아래를 **순서대로** 실행합니다.

```powershell
cd "C:\Users\woohyeon\Desktop\취미\onairkit"

git init
git add .
git commit -m "온에어킷 위젯 5종 + 문서 첫 배포"
git branch -M main
git remote add origin https://github.com/onairkit/onairkit.github.io.git
git push -u origin main
```

위 주소는 조직 `onairkit` 의 저장소를 가리킵니다. 이미 실제 값이라 그대로 붙여 넣으면 됩니다.

각 명령이 하는 일:

| 명령 | 하는 일 |
|---|---|
| `git init` | 이 폴더를 git이 관리하도록 시작 (이미 되어 있으면 그냥 넘어갑니다) |
| `git add .` | 폴더 안 모든 파일을 "올릴 목록"에 담기 |
| `git commit -m "..."` | 지금 상태를 하나의 기록으로 저장. 따옴표 안은 설명 문구 |
| `git branch -M main` | 기본 가지 이름을 `main` 으로 맞추기 (GitHub Pages 설정과 일치시키기 위해) |
| `git remote add origin ...` | "이 폴더는 저 GitHub 저장소와 연결된다"고 알려 주기 |
| `git push -u origin main` | 실제로 올리기 |

### B-4. 로그인 창이 뜨면

`git push` 를 하면 브라우저 로그인 창이나 인증 창이 뜹니다.

- **브라우저 창이 뜨는 경우** → `Authorize` 를 눌러 승인하면 끝입니다. 가장 쉽습니다.
- **아이디/비밀번호를 묻는 경우** → GitHub는 2021년부터 **계정 비밀번호를 받지 않습니다.**
  대신 **개인 액세스 토큰(Personal Access Token)** 을 만들어 비밀번호 자리에 넣어야 합니다.

<details>
<summary>개인 액세스 토큰 만드는 법 (펼쳐 보기)</summary>

1. github.com 로그인 → 오른쪽 위 프로필 사진 → **`Settings`**
2. 왼쪽 목록 맨 아래 **`Developer settings`**
3. **`Personal access tokens`** → **`Tokens (classic)`**
4. **`Generate new token`** → **`Generate new token (classic)`**
5. Note에 아무 이름 (예: `onairkit 배포`), Expiration은 원하는 기간
6. **`repo`** 항목에 체크
7. 아래 **`Generate token`** 클릭
8. 화면에 뜬 긴 문자열(`ghp_...`)을 **즉시 복사**합니다. **이 화면을 벗어나면 다시 볼 수 없습니다.**
9. `git push` 가 비밀번호를 물으면 이 토큰을 붙여넣습니다. (붙여넣어도 화면에 아무것도 안 보이는 게 정상)

토큰은 비밀번호와 같습니다. 남에게 보여 주거나 파일에 적어 저장소에 올리지 마세요.

</details>

### B-5. `_ref` 폴더는 안 올라갑니다

이 프로젝트의 `.gitignore` 에 `_ref/` 가 들어 있어서, 작업용 참고 자료는 자동으로 제외됩니다.
의도된 동작입니다. 배포에 필요 없는 파일이라 올리지 않습니다.

## 3. GitHub Pages 켜기

> **`onairkit.github.io` 저장소는 Pages가 대개 자동으로 켜집니다.**
> 파일을 올린 뒤 몇 분 기다렸다가 `https://onairkit.github.io/` 를 먼저 열어 보세요.
> 랜딩 페이지가 뜨면 이 장은 건너뛰어도 됩니다. 안 뜨면 아래대로 직접 켜세요.

파일을 올렸다고 바로 웹사이트가 되는 건 아닙니다. Pages 기능을 켜야 합니다.

| 단계 | 할 일 |
|---|---|
| 1 | 저장소 화면 위쪽 탭에서 **`Settings`** (톱니바퀴) 클릭 |
| 2 | 왼쪽 목록에서 **`Pages`** 클릭 |
| 3 | **Source** 항목이 **`Deploy from a branch`** 인지 확인 |
| 4 | **Branch** 에서 왼쪽 드롭다운을 **`main`** 으로 |
| 5 | 오른쪽 드롭다운(폴더)을 **`/ (root)`** 로 |
| 6 | **`Save`** 클릭 |

> **`main` 이 목록에 없다면** 파일이 아직 안 올라갔거나 가지 이름이 `master` 인 경우입니다.
> 저장소 첫 화면에 파일이 보이는지 먼저 확인하고, 가지 이름이 `master` 로 되어 있으면 `master` 를 고르세요.
>
> **`/ (root)` vs `/docs`** — 우리는 위젯이 `widgets/` 에 있고 저장소 최상단부터 통째로 서빙해야 하므로
> 반드시 **`/ (root)`** 를 골라야 합니다. `/docs` 를 고르면 위젯 주소가 깨집니다.

**기다리기** — 저장 후 **1~3분** 정도 걸립니다. 처음 배포는 5분 넘게 걸릴 때도 있습니다.
같은 Pages 화면을 새로고침하면 위쪽에 이런 문구가 나타납니다.

```
Your site is live at https://onairkit.github.io/
```

저장소 위쪽 **`Actions`** 탭에서 배포 진행 상황을 볼 수 있습니다.
초록 체크 표시가 뜨면 완료, 빨간 X 면 실패입니다.

## 4. 주소 확인하고 OBS에 넣기

### 파라미터 붙이기

로컬 파일과 달리 **주소 뒤에 그냥 붙이면 됩니다.** 아무 설정도 필요 없습니다.

```
https://onairkit.github.io/widgets/telop.html?text=오늘 9시 시청자 참여전&theme=news&label=속보

https://onairkit.github.io/widgets/queue.html?title=오늘의 시참&max=8&theme=pastel&pos=tr

https://onairkit.github.io/widgets/roulette.html?items=치킨|피자|족발|마라탕&title=오늘 저녁 뭐 먹지
```

### 확인 순서

1. **브라우저에서 먼저 열어 보세요.** 위젯이 뜨면 성공입니다.
2. 주소창에서 파라미터를 이리저리 바꿔 보며 원하는 모습을 만듭니다.
3. 마음에 들면 **주소창 내용을 통째로 복사**합니다.
4. OBS에서 소스 `+` → **브라우저** → **"로컬 파일" 체크는 그대로 꺼 둔 채** URL 칸에 붙여넣기
5. 폭 `1920` / 높이 `1080` → 확인

자세한 OBS 설정은 [OBS설정법.md](OBS설정법.md)를 보세요.

> **주의: 인터넷이 끊기면 온라인 위젯은 안 뜹니다.**
> 방송 안정성이 중요하다면 중요한 위젯은 로컬 파일 방식으로 백업 소스를 하나 더 만들어 두세요.

## 6. 캐시 주의사항

**캐시(cache)** = 같은 파일을 매번 다시 받지 않으려고 임시로 저장해 두는 것.
빨라서 좋지만, **파일을 고쳤을 때 예전 내용이 계속 보이는** 원인이 됩니다.

온라인 배포에서는 캐시가 **세 군데**에 있습니다.

| 어디 | 얼마나 | 어떻게 뚫나 |
|---|---|---|
| GitHub Pages CDN 서버 | 보통 몇 분 | 기다리기 (강제할 방법 없음) |
| 내 웹 브라우저 | 오래 | `Ctrl + Shift + R` (강력 새로고침) |
| **OBS 내장 브라우저** | 오래 | 소스 우클릭 → `새로고침` |

### 확실하게 최신을 보는 순서

1. `Actions` 탭에서 배포가 끝났는지(초록 체크) 확인
2. 크롬에서 그 주소를 열고 **`Ctrl + Shift + R`**
3. 크롬에서 최신이 보이면, OBS에서 그 소스를 **우클릭 → `새로고침`**
4. 그래도 예전 것이면 **주소 끝에 버전 표시를 붙입니다**

```
https://onairkit.github.io/widgets/telop.html?text=안녕&v=2
```

다음에 또 안 바뀌면 `v=3`, `v=4` 로 올리세요.
온에어킷 위젯은 모르는 파라미터를 조용히 무시하므로 `v` 를 아무리 붙여도 안전합니다.
**주소가 달라지면 캐시는 그것을 새 파일로 보고 반드시 새로 받아 갑니다.** 가장 확실한 방법입니다.

### 방송 직전에는 업데이트하지 마세요

캐시 반영 시점을 통제할 수 없으므로, **방송 시작 30분 전부터는 배포하지 마세요.**
업데이트 후에는 반드시 OBS에서 소스를 새로고침하고 화면을 눈으로 확인한 뒤 방송을 시작하세요.

### 저장된 값(localStorage)은 캐시와 다릅니다

카운터 숫자, 대기열 목록, 룰렛 남은 항목은 **캐시가 아니라 브라우저 저장소**에 있습니다.
새로고침해도 안 바뀝니다. 이건 `&reset=1` 을 붙여 한 번 불러와야 초기화됩니다.

## 7. (선택) 내 도메인 연결하기

`https://widget.내도메인.com/telop.html` 같은 주소를 쓰고 싶을 때만 하면 됩니다.
**안 해도 아무 문제 없습니다.** 도메인은 유료(연 1~2만원 수준)입니다.

| 단계 | 할 일 |
|---|---|
| 1 | 도메인 구입 (가비아, 호스팅케이알, Cloudflare Registrar 등) |
| 2 | 도메인 관리 화면에서 **CNAME 레코드** 추가<br>호스트: `widget` / 값: `onairkit.github.io` |
| 3 | GitHub 저장소 → `Settings` → `Pages` → **Custom domain** 칸에 `widget.내도메인.com` 입력 → `Save` |
| 4 | 몇 분~몇 시간 기다린 뒤 **`Enforce HTTPS`** 체크 (체크가 활성화될 때까지 기다려야 함) |

- 최상위 도메인(`내도메인.com`)을 쓰려면 CNAME 대신 **A 레코드 4개**를 GitHub 지정 IP로 등록해야 합니다.
  GitHub Pages 공식 문서의 "Managing a custom domain" 항목을 참고하세요.
- 도메인을 연결하면 **기존 `github.io` 주소도 계속 동작**합니다. OBS에 이미 넣어 둔 주소를 급히 바꿀 필요는 없습니다.
- DNS 반영에 최대 24~48시간이 걸릴 수 있습니다. 방송 일정에 여유를 두고 하세요.

## 8. 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 주소를 열면 **404 Not Found** | 배포가 아직 안 끝났거나 경로가 틀림 | 1~3분 더 기다리기 → `Actions` 탭에서 초록 체크 확인 → 주소의 대소문자·`widgets` 철자 확인 |
| 404가 계속됨 | Pages 설정의 폴더가 `/docs` 로 되어 있음 | `Settings` → `Pages` → Branch 오른쪽 드롭다운을 **`/ (root)`** 로 변경 |
| 위젯 대신 **README 글자만** 나옴 | 저장소 루트(`/`)를 연 것 | 주소 뒤에 `/widgets/telop.html` 을 붙여야 합니다 |
| 위젯 대신 **HTML 소스코드**가 글자로 보임 | 파일 확장자가 `.html` 이 아님 | 파일 이름을 확인하고 `.txt` 등이 붙었으면 고쳐서 다시 올리기 |
| **일부 파일이 안 올라감** | `.nojekyll` 이 없음 | 저장소에 `.nojekyll` 빈 파일을 만들어 커밋 |
| 파일을 고쳤는데 그대로 | 캐시 | [6번 항목](#6-캐시-주의사항) 참고. `?v=2` 를 붙이는 게 가장 확실 |
| `git push` 에서 **rejected** | 저장소에 내가 모르는 커밋이 있음 | `git pull --rebase origin main` 후 다시 `git push` |
| `git push` 에서 **Authentication failed** | 비밀번호 대신 토큰이 필요 | [B-4의 토큰 만들기](#b-4-로그인-창이-뜨면) 참고 |
| `remote origin already exists` | 이미 연결되어 있음 | `git remote set-url origin https://github.com/onairkit/onairkit.github.io.git` 로 주소만 교체 |
| Pages 메뉴에 `main` 이 안 보임 | 파일이 아직 안 올라갔음 | 저장소 첫 화면에 파일이 보이는지 확인. 없으면 업로드부터 다시 |
| 한글 파일명 문서 링크가 깨짐 | 주소에서 한글이 인코딩됨 | 정상입니다. GitHub 화면에서 파일을 클릭해 들어가면 잘 열립니다 |
| 실수로 개인정보를 올림 | 공개 저장소 | 즉시 그 파일을 삭제하고 커밋. 이미 노출됐다면 해당 키·비밀번호를 **폐기하고 새로 발급**하세요 |
