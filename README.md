# 온에어킷 (onairkit)

**치지직 · SOOP · 트위치 스트리머를 위한 무료 OBS 위젯 모음.**
파일 하나가 위젯 하나입니다. 설치도, 회원가입도, 서버도 필요 없습니다.

---

## 완전 무료입니다

| 항목 | 온에어킷 |
|---|---|
| 이용료 | **0원** (구독 없음, 결제 화면 없음) |
| 회원가입 | 필요 없음 |
| 상업적 이용 | 가능 (수익 창출 방송에 그대로 써도 됩니다) |
| 워터마크 | 오른쪽 아래 작은 "온에어킷" 글씨 — `credit=0` 으로 끌 수 있습니다 |
| 라이선스 | MIT ([LICENSE](LICENSE)) |

크레딧을 꺼도 아무 기능 제한이 없습니다. 다만 켜 두시면 다른 스트리머가 이 위젯을 알게 되고,
그만큼 위젯이 계속 늘어납니다. 켜 두시면 정말 감사합니다.

## 위젯 5종

| 위젯 | 무엇을 하나 | 자주 쓰는 파라미터 | 파일 |
|---|---|---|---|
| **텔롭 (자막)** | 화면 아래 예능·뉴스 스타일 자막 바. 여러 문구 자동 순환, 뉴스처럼 흐르는 티커 | `text` (여러 문구는 `\|` 로 구분) · `label` (왼쪽 칩) · `mode` (`slide`/`fade`/`ticker`) · `interval` · `speed` | [widgets/telop.html](widgets/telop.html) |
| **타이머 / 카운트다운** | "방송 시작까지 N분", 휴식 타이머, 방송 경과 시간, 현재 시각 시계 | `mode` (`until`/`after`/`up`/`clock`) · `minutes` · `until` · `label` · `done` · `onend` · `format` · `bar` | [widgets/timer.html](widgets/timer.html) |
| **카운터** | 데스카운트, 승패, 내기 횟수. 값이 자동 저장되어 OBS를 껐다 켜도 유지 | `label` · `value` · `step` · `min` / `max` · `goal` · `icon` · `id` (여러 개 쓸 때) | [widgets/counter.html](widgets/counter.html) |
| **시참 대기열** | 시청자 참여 순서 목록. 방송 중에 직접 추가 / 완료 / 삭제 | `title` · `names` (`\|` 로 구분) · `max` · `numbered` · `current` | [widgets/queue.html](widgets/queue.html) |
| **룰렛** | 벌칙·메뉴·시청자 추첨 원판. 돌리면 위쪽 포인터가 가리킨 항목이 당첨 | `items` (`\|` 로 구분, 2~12개) · `title` · `duration` · `remove` · `result` · `diameter` | [widgets/roulette.html](widgets/roulette.html) |

> **파라미터(parameter)** 란, 위젯 주소 뒤에 `?이름=값` 형태로 붙여서 위젯의 모양이나 내용을 바꾸는 설정값입니다.
> 여러 개를 붙일 때는 `&` 로 이어 붙입니다. 예: `?text=안녕하세요&theme=news&size=40`

각 위젯 파일을 **메모장으로 열면 맨 위에 그 위젯의 전체 파라미터 표와 예시 URL**이 한국어로 들어 있습니다.
이 README는 요약본이고, 정확한 최신 사양은 항상 위젯 파일 상단 주석이 기준입니다.

## 5종 공통 파라미터

아래 파라미터는 위젯 5개 모두에서 똑같이 동작합니다.

| 이름 | 설명 | 기본값 | 허용 범위 |
|---|---|---|---|
| `theme` | 색·모서리·그림자 프리셋 | `default` | `default` / `news` / `pastel` / `minimal` |
| `accent` | 포인트 색 (hex, `#` 생략 가능) | 테마별 기본값 | 3자리 또는 6자리 hex. 예: `ffd166` |
| `dark` | 어두운 배경(1) / 밝은 배경(0) | 테마별 기본값 | `1` / `0` |
| `size` | 기준 글자 크기(px) | 위젯마다 다름 | 16 ~ 120 |
| `pos` | 화면 안에서의 위치 | 위젯마다 다름 | `tl` `tc` `tr` `bl` `bc` `br` `c` |
| `margin` | 화면 가장자리 여백(px) | 48 | 0 ~ 400 |
| `credit` | 오른쪽 아래 크레딧 | `1` | `1` 표시 / `0` 숨김 / 그 외 문자열이면 그 문구로 교체 |
| `reset` | 저장된 상태를 무시하고 처음부터 시작 | (없음) | `1` |

**`pos` 값 읽는 법** — 앞 글자는 위아래(`t`=위, `b`=아래), 뒷 글자는 좌우(`l`=왼쪽, `c`=가운데, `r`=오른쪽)입니다.
`tl`=좌상단, `tc`=상단 중앙, `tr`=우상단, `bl`=좌하단, `bc`=하단 중앙, `br`=우하단, `c`=화면 정중앙.

**`theme` 4종**

| 값 | 느낌 | 기본 포인트 색 | 기본 배경 |
|---|---|---|---|
| `default` | 네온 그린, 둥근 모서리. 게임 방송 기본 | `#00ffa3` | 다크 |
| `news` | 속보 레드, 각진 모서리. 뉴스·긴급 공지 느낌 | `#ff2d55` | 다크 |
| `pastel` | 파스텔 핑크, 크게 둥근 모서리. 부드러운 감성 | `#ff8fb1` | 라이트 |
| `minimal` | 흑백 미니멀, 그림자 최소 | `#1a1a1a` | 라이트 |

`theme` 이 `accent` 와 `dark` 의 기본값을 정합니다. `accent` 나 `dark` 를 직접 쓰면 그 값이 우선입니다.

> 숫자나 목록 파라미터에 이상한 값을 넣어도 위젯이 깨지지 않습니다.
> 숫자는 허용 범위 안으로 잘라내고(`size=-999` → `16`), 못 알아듣는 값은 조용히 기본값으로 돌아갑니다.

## 30초 시작 가이드

> **가장 빠른 길** — `index.html` 을 열어 **URL 빌더**에서 설정하고 `[URL 복사]` 를 누른 뒤,
> OBS 브라우저 소스의 URL 칸에 붙여넣으세요. 아래 단계는 파일을 직접 받아 쓰는 방법입니다.

1. **파일 받기** — 이 저장소 오른쪽 위 초록색 `Code` 버튼 → `Download ZIP` → 압축을 풀고 원하는 폴더에 둡니다.
   (예: `C:\onairkit`)
2. **미리 보기** — `widgets` 폴더의 원하는 HTML 파일을 **더블클릭**하면 브라우저에서 바로 보입니다.
   기본값만으로 이미 그럴듯하게 나옵니다.
3. **OBS에 올리기** — OBS 소스 목록에서 `[+]` → **브라우저** → 이름 입력 → 확인
   → **"로컬 파일" 체크** → `찾아보기` 로 그 HTML 파일 선택
   → **폭 `1920` / 높이 `1080`** 입력 → 확인
4. **위치 잡기** — 미리보기 화면에서 빨간 테두리를 드래그해 원하는 자리로 옮기고 크기를 조절합니다.
5. **내용 바꾸기** — 두 가지 방법 중 편한 쪽:
   - **메모장 방식** — HTML 파일을 메모장으로 열어 `<script>` 맨 위 `CONFIG` 안의 값만 고칩니다.
   - **URL 방식** — OBS 브라우저 소스 속성에서 **"로컬 파일" 체크를 해제**하고 URL 칸에 이렇게 넣습니다.
     ```
     file:///C:/onairkit/widgets/telop.html?theme=news&label=속보&text=오늘 밤 9시 시청자 참여전
     ```
     경로 구분자는 역슬래시(`\`)가 아니라 **슬래시(`/`)** 입니다.

막히면 → **[docs/OBS설정법.md](docs/OBS설정법.md)** 에 그림 없는 초보자용 단계별 설명과 문제 해결이 전부 들어 있습니다.

### 방송 중에 위젯을 조작하려면

OBS의 송출 화면에는 마우스 커서가 없습니다. 조작은 **소스 목록에서 해당 브라우저 소스를 우클릭 → "상호작용"** 창에서만 됩니다.
그래서 온에어킷 위젯의 조작 버튼은 평소 완전히 투명하고, **"상호작용" 창에서 위젯 위에 마우스를 올렸을 때만** 나타납니다.
방송 화면에는 절대 보이지 않습니다.

| 위젯 | 조작 | 단축키 (상호작용 창에 포커스를 준 뒤) |
|---|---|---|
| 텔롭 | 이전 / 일시정지 / 다음 | `←` 이전, `→` 다음, `Space` 일시정지 |
| 타이머 | −1분 / +1분 / 일시정지 / 리셋 | `↑` +1분, `↓` −1분, `Space` 일시정지, `R` 리셋 |
| 카운터 | − / + / 리셋 | `↑` `+` 증가, `↓` `-` 감소, `R` 리셋 |
| 대기열 | 입력창 + 추가, 각 줄 완료 / 삭제 | 입력창 안 `Enter` 추가, 밖 `Space`/`Enter` 맨 위 완료, `R` 리셋 |
| 룰렛 | 원판 클릭 또는 돌리기 / 리셋 | `Space` 돌리기, `R` 리셋 |

값(대기열, 카운터 숫자, 남은 시간 등)은 브라우저에 자동 저장(localStorage)되어 OBS를 껐다 켜도 유지됩니다.
처음부터 다시 시작하려면 URL 뒤에 `&reset=1` 을 붙여 한 번 불러오세요.

### 위젯 파일에 대해 알아 두면 좋은 것

- **외부 이미지·폰트 파일이 없습니다.** HTML 하나로 끝납니다.
  글꼴 Pretendard의 CSS 한 개만 인터넷에서 불러오며, 인터넷이 끊겨도 시스템 기본 글꼴로 정상 동작합니다.
- **배경이 투명**하고 `overflow:hidden` 이라 게임 화면 위에 그대로 올리면 됩니다.
- **1920×1080 기준**으로 디자인되었습니다. 브라우저 소스 크기를 이 값으로 맞추고, 크기 조절은 OBS 화면에서 하세요.
- 서버·로그인·데이터베이스를 쓰지 않습니다. 여러분의 방송 데이터가 어디로도 전송되지 않습니다.
